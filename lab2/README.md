# Лабораторная работа №2 — Виртуальный датчик для контроля процесса обжига в печи

## Состав репозитория

- `predictive_analytics_lab2_virtual_sensor.ipynb` — Jupyter Notebook с полным пайплайном решения.
- `data_train.csv` — минутная телеметрия 16 датчиков.
- `target_train.csv` — лабораторные замеры целевой концентрации.
- `requirements.txt` — зависимости.
- `outputs/` — рассчитанные таблицы с метриками, лаговыми корреляциями, важностью признаков и прогнозами.

## Как запустить

```bash
pip install -r requirements.txt
jupyter notebook predictive_analytics_lab2_virtual_sensor.ipynb
```

Далее выполнить все ячейки сверху вниз.

## Логика решения

1. Телеметрия агрегируется по времени, дубликаты временных меток усредняются.
2. Данные приводятся к минутной сетке, пропуски интерполируются по времени.
3. Выбросы ограничиваются квантилями 0.5% и 99.5%.
4. Лабораторные замеры сдвигаются на 15 минут назад, так как результат анализа приходит с задержкой 10–15 минут.
5. Строятся лаговые признаки, скользящие статистики и признаки динамики.
6. Обучаются модели Ridge, ExtraTrees, GradientBoosting и SARIMAX baseline.
7. Модели сравниваются по MAE, RMSE, MAPE, WAPE, directional accuracy, AIC/BIC и времени обучения.

## Краткие результаты на train split 80/20

| Модель | MAE | RMSE | WAPE, % | Direction accuracy, % |
|---|---:|---:|---:|---:|
| Ridge | 0.0853 | 0.1038 | 37.74 | 54.52 |
| ExtraTrees | 0.0726 | 0.0891 | 32.12 | 50.56 |
| GradientBoosting | 0.0748 | 0.0917 | 33.10 | 51.41 |
| SARIMAX target only | 0.0703 | 0.0842 | 31.14 | 12.99 |

SARIMAX показывает хороший RMSE, но не использует телеметрию, поэтому для промышленного виртуального датчика предпочтительнее рассматривать ансамблевые ML-модели, которые связывают прогноз с датчиками печи и дают интерпретируемую важность признаков.

## Интерпретация

Ключевые признаки по лаговой корреляции: `telemetry_15`, `telemetry_3`, `telemetry_0`, `telemetry_12`, `telemetry_13`, `telemetry_9`.

Важность лагов и скользящих статистик подтверждает инерционность процесса обжига: концентрация продукта зависит не только от текущего состояния печи, но и от истории изменения режима.
