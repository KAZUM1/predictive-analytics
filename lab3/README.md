# Лабораторная работа №3: классификация временных рядов и прогнозирование метеоданных

## Описание

Проект реализует двухэтапную систему анализа временных рядов метеоданных шести городов России:

1. **Классификация климатического типа** по 30-дневному окну погодных наблюдений.
2. **Прогнозирование температуры на 30 дней вперед** отдельными моделями для каждого города.

Города: Москва, Санкт-Петербург, Сочи, Геленджик, Благовещенск, Находка.  
Период данных: 2019–2025 годы.  
Частота исходных данных: почасовая. Для месячного прогноза используется дневная агрегация.

## Как запустить

1. Создать виртуальное окружение:

```bash
python -m venv .venv
source .venv/bin/activate        # Linux/macOS
# .venv\Scripts\activate         # Windows
```

2. Установить зависимости:

```bash
pip install -r requirements.txt
```

3. Запустить Jupyter Notebook:

```bash
jupyter notebook predictive_analytics_lab3_weather_timeseries.ipynb
```

4. Выполнить все ячейки сверху вниз. Результаты сохраняются в папку `lab3_outputs`.

## Что реализовано в notebook

- загрузка и объединение parquet-файлов;
- EDA по всем городам: тренды, сезонность, распределения, Q-Q plot, корреляции, выбросы, пропуски;
- межгородской анализ температур и осадков;
- проверка стационарности тестом Дики-Фуллера;
- временные признаки, циклические признаки, лаги, rolling-статистики, признаки динамики;
- PCA-визуализация разделимости городов;
- классификация климатической зоны по 30-дневному окну;
- метрики классификации: Accuracy, Precision, Recall, F1-score, confusion matrix, ROC-AUC OvR;
- анализ качества классификации по месяцам и сезонам;
- прогноз температуры на горизонты 1–30 дней для каждого города;
- модели прогнозирования: Ridge, Random Forest, HistGradientBoosting;
- метрики прогноза: MAE, RMSE, MAPE, WAPE, direction accuracy;
- анализ остатков: Shapiro-Wilk, Ljung-Box, White test;
- permutation importance для классификации и прогнозирования;
- интеграция в класс `TwoStageWeatherPipeline`.

## Интерпретация подхода

Двухэтапный подход полезен, потому что метеорологические ряды разных городов имеют разные климатические режимы. Универсальная модель может сглаживать региональные особенности, а отдельные модели по городам лучше учитывают локальную сезонность, влажность, давление, осадки и силу ветра.

## Примечания

- Выбросы в погодных данных не удаляются автоматически, так как экстремальные значения могут отражать реальные опасные явления.
- Пропуски обрабатываются временной интерполяцией внутри города.
- Для прогнозирования используется дневная агрегация, потому что целевой горизонт — месяц вперед.
